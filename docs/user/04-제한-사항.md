# 04 제한 사항 (얼리 액세스)

이 버전을 현장에 쓰기 전에 아래를 확인하세요.

## 지원하는 것

- 장치 통신: **MODBUS TCP** 읽기(코일, 이산 입력, 보유·입력 레지스터)와 단일 쓰기(코일, 레지스터).
- 값 환산, 알람 종류 0~9와 디지털 알람 0~3, 복귀 여유.
- 웹 UI(태그·알람·이력·공정 화면·프로젝트 편집), 로컬 계정과 역할, 감사 기록, 알람 이력과 확인(ACK).
- Windows·Linux·macOS에서 빌드·시험됩니다(배포 묶음은 릴리스 페이지의 조합만).

## 검증 수준

- 장치 통신은 **시뮬레이터로만 시험했고 실제 PLC로는 시험하지 않았습니다.** 장치마다 다른 동작(주소 규칙, 응답 지연, 바이트 순서)이 있을 수 있습니다.
- 부하 측정: 개발 기계(15코어·24 GB)와 CI에서 태그 1만 개·브라우저 50개·스캔 100 ms로 지터가 목표(주기의 20%) 안이었습니다. **권장 하드웨어(4코어·8 GB)나 실제 네트워크에서는 측정하지 않았습니다.** 72시간 연속 운전 시험은 진행 중입니다.
- 보안: **외부 보안 검토를 받지 않았습니다.** 인증(IEC 62443 등)을 목표로 하지 않습니다.
- 기존 제품 호환은 합성 데이터로만 시험했습니다. 태그 파일(`Local.tagx`) 읽기는 문서화된 필드 순서에 따라 만들었지만 **실제 기존 제품이 만든 파일로 검증하지 않았고**, 통신 설정(포트·국번·주소)은 추정해 옮깁니다.

| 가져오기 | 웹 가져오기 화면(API만 있음), 포트 설정·화면 파일·문자열 태그 가져오기 |

## 사용하면 안 되는 용도

- 비상 정지, 인터록, 안전 계전기 대체 등 **인명·설비 안전을 보장하는 기능**.
- 인터넷에 직접 노출하는 제어 시스템.
- 이 소프트웨어는 Apache License 2.0에 따라 **보증 없이 "있는 그대로"** 제공됩니다. 사용으로 생긴 손해에 개발자와 기여자는 책임을 지지 않습니다([LICENSE](../../LICENSE), [SAFETY.md](../../SAFETY.md)).
