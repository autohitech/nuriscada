# 01 시작하기

NuriScada를 내려받아 시험용 장치 시뮬레이터와 함께 5분 안에 실행해 봅니다.

## 요구 사항

- Windows 10 이상, 주요 Linux, macOS(arm64) 중 하나. x86-64와 arm64를 목표로 하지만 **배포 묶음은 릴리스 페이지에 있는 조합만** 제공합니다.
- 최신 브라우저(Chrome, Edge, Firefox, Safari). 설치할 것은 없습니다.
- 인터넷 연결이 필요 없습니다. 웹 화면에 외부 글꼴·스크립트가 없습니다.

## 1. 내려받기와 풀기

릴리스 페이지에서 사용하는 운영체제용 묶음(`nuriscada-<버전>-<OS>-<CPU>.tar.gz` 또는 `.zip`)과 `SHA256SUMS`를 받습니다.

```sh
# 무결성 확인(macOS/Linux)
shasum -a 256 -c SHA256SUMS --ignore-missing
tar xzf nuriscada-*.tar.gz
cd nuriscada-*/
```

Windows는 `.zip`을 풀고 PowerShell에서 `Get-FileHash`로 `SHA256SUMS`의 값과 비교합니다.

> **서명되지 않은 프로그램입니다.** 초기 버전은 코드 서명이 없어서 운영체제가 경고할 수 있습니다.
> - macOS: 처음 실행할 때 막히면 `xattr -dr com.apple.quarantine .`을 묶음 폴더에서 실행하거나, 시스템 설정의 "개인정보 보호 및 보안"에서 허용합니다.
> - Windows: SmartScreen이 막으면 "추가 정보 → 실행"을 고릅니다.
> 해시를 확인한 파일만 실행하세요.

## 2. 시연 실행

터미널 두 개를 엽니다(묶음 폴더에서).

**터미널 1 — 장치 시뮬레이터** (가상 MODBUS TCP 장치, 값이 계속 변합니다)

```sh
bin/nuriscada-sim-modbus --demo
```

**터미널 2 — 서버**

```sh
# 최초 한 번: 관리자 계정 만들기(비밀번호는 화면에 보이지 않게 입력, 12~128 바이트)
bin/nuriscada-server --config examples/demo.toml --init-admin admin

# 서버 시작
bin/nuriscada-server --config examples/demo.toml
```

브라우저에서 **http://127.0.0.1:8080/** 을 열고 방금 만든 계정으로 로그인합니다.

화면에서 볼 수 있는 것:
- **언어**: 상태 줄 오른쪽의 선택 상자에서 한국어·영어를 고릅니다(처음에는 브라우저 언어를 따릅니다).
- **태그 표**: 값, 상태(정상·상한·하한 등), 통신 불량 표시. 검색 상자로 이름을 걸러 냅니다.
- **알람 패널**: 활성 알람과 최근 기록. 운전원·관리자는 알람을 확인(ACK)합니다.
- **이력**: 태그를 골라 시계열 그래프와 최소·최대·최신 값을 보고 CSV로 내려받습니다.
- **공정 화면**: 탱크·게이지·펌프 같은 심볼 화면(`examples/demo.toml`에 예제가 있습니다).
- **프로젝트 편집**(관리자): 장치·태그·화면을 웹에서 추가·수정합니다. [02 프로젝트 설정](02-프로젝트-설정.md)을 보세요.

서버를 멈추려면 터미널에서 `Ctrl+C`를 누릅니다.

> 시연은 `examples/` 안에 데이터 폴더 `.nuriscada`를 만듭니다. 실제로 쓸 때는 설정 파일을 **별도 폴더에 복사**해 거기서 실행하세요(데이터가 설정 파일 옆에 만들어집니다).

## 3. 자기 장치에 연결하기

1. `examples/demo.toml`을 복사해 새 파일을 만들고 `[[device]]`의 `address`를 실제 MODBUS TCP 장치(`호스트:포트`, 보통 `192.168.0.10:502`)로 바꿉니다.
2. 태그의 `space`(영역)·`address`(주소)·`unit`(유닛 번호)을 장치 문서에 맞춥니다. 자세한 항목은 [02 프로젝트 설정](02-프로젝트-설정.md)에 있습니다.
3. 새 설정 파일로 관리자를 만들고(`--init-admin`) 서버를 시작합니다. 데이터는 설정 파일 옆 `.nuriscada` 폴더에 저장됩니다.

> **먼저 시험 장비로 확인하세요.** 이 소프트웨어는 실제 PLC와 연결해 검증하지 않았습니다. 설비에 연결하기 전에 시험 환경에서 값과 알람을 충분히 확인하세요. **쓰기(제어)는 기본으로 꺼져 있고**, 켜는 방법은 [03 운영과 보안](03-운영과-보안.md)에 있습니다.
