# 설계 0008. 디자인 토큰과 공용 부품

> 상태: 고정 [O] (SQ-U01). 토큰 추가·변경은 이 문서와 `web/src/styles/tokens.css`를 함께 고친다.

## 토큰

색·타이포·간격·모서리는 토큰으로만 쓴다. 부품 파일에 16진 색을 직접 적지 않는다.
`var(--이름, 폴백)`의 폴백은 새 토큰을 넣기 전 임시로만 두고, 토큰 정의 뒤에는 지운다.

| 분류 | 토큰 | 용도 |
|---|---|---|
| 바탕 | `--bg`, `--surface`, `--surface-2`, `--border` | 배경·판·구분선 |
| 글 | `--text`, `--muted` | 본문·보조 |
| 강조 | `--accent`, `--focus` | 선택·키보드 초점(`--focus`는 `:focus-visible` 외곽선) |
| 상태 | `--ok` | 정상(저채도, 평상시 강조 안 함) |
| 상태 | `--warn`, `--warn-bg` | 주의(HIGH·LOW) |
| 상태 | `--critical`, `--critical-bg` | 경보(HIHI·LOLO) |
| 상태 | `--info`, `--info-bg` | 알림(MIDDLE·디지털 변화) |
| 상태 | `--bad`, `--bad-bg` | 통신 끊김(점선 테두리와 함께) |
| 글꼴 | `--font`, `--mono` | 시스템 글꼴만(외부 글꼴 금지, 결정 0003) |
| 치수 | `--radius: 6px`, `--gap: 12px`, `--row-h: 36px`, `--touch-min: 44px` | 모서리·간격·행 높이·최소 터치 대상 |

세 테마(`dark`·`light`·`contrast`)는 같은 토큰 집합을 같은 의미로 정의한다.
토큰 집합이 어긋나면 테마마다 다른 색이 나온다. 세 테마의 토큰 이름 집합은 항상 같게 둔다.

## 상태 색 체계

고정 표는 [결정 0004](../decisions/0004-design-direction.md)의 상태 색 체계 절을 따른다.
색만으로 구분하지 않고 아이콘 모양(`StateChip`)과 문구를 함께 쓴다.

## 공용 부품

| 부품 | 용도 |
|---|---|
| `StateChip` | 심각도 칩(색+아이콘+문구). 심각도별 모양은 이 부품 하나에만 둔다 |
| `StatusBar` | 장치·스캔·지터·재시작 요약 |
| `TagTable` | 값·품질·알람 목록 |
| `AlarmPanel` | 활성 알람·최근 기록, 화면 낭독기 알림 포함 |
| `GraphicScreen` | 런타임 화면·편집기(스냅·실행 취소 포함) |
| `OperationsPanel` | 쓰기 확인·묶음 쓰기·프로젝트 편집·가져오기·이력 조회 |
## 심볼 라이브러리와 상태 외형(SQ-G04)

런타임 위젯 8종의 상태별 외형 규칙(고정). 위젯 `id`가 연결 단위다.

| 위젯 | 정지 | 운전 | 경보 | 고장(통신 끊김) |
|---|---|---|---|---|
| 탱크·게이지 | 채움 비율(값·min·max) | 채움 비율 | 테두리 `--critical` + 경보 문구 | 테두리 `--bad` 점선 + 통신 불량 문구 |
| 펌프 | 회전 삼각형 `--muted`, 정지 문구 | 삼각형·테두리 `--ok`, 운전 문구 | 테두리 `--critical` + 경보 문구 | 테두리 `--bad` 점선 + 통신 불량 문구 |
| 모터 | 원 안 M `--muted`, 정지 문구 | 원·M `--ok`, 운전 문구 | 테두리 `--critical` + 경보 문구 | 테두리 `--bad` 점선 + 통신 불량 문구 |
| 밸브 | 나비 `--muted`, 정지 문구 | 나비·테두리 `--ok`, 운전 문구 | 테두리 `--critical` + 경보 문구 | 테두리 `--bad` 점선 + 통신 불량 문구 |
| 상태 램프 | 빈 원 `--muted`, 소등 문구 | 채운 원 `--ok`, 점등 문구 | 테두리 `--critical` + 경보 문구 | 테두리 `--bad` 점선 + 통신 불량 문구 |
| 값 표시기·문구 | 값·문구 `--text` | 값·문구 `--text` | 값 `--critical` + 경보 문구 | 값 `--bad` + 통신 불량 문구 |

운전·정지는 디지털 참/거짓(아날로그는 0 초과)으로 판단한다. 경보는 알람 상태, 고장은 품질 `bad`로 판단한다.
## 벡터 선명도

런타임 화면·트렌드·상태 칩은 SVG 도형과 글자만 쓴다. `<canvas>`·`<img>`·`<image>`를 쓰지 않는다.
화면·차트는 `viewBox`로 그리고 브라우저 확대·고DPI에서도 다시 그려지므로 깨지지 않는다(SQ-G01).

## 모션

장식 모션을 쓰지 않는다. 움직임은 상태 변화 전달에만 쓴다.
`prefers-reduced-motion: reduce`에서는 애니메이션·전이를 끈다(`tokens.css`).
