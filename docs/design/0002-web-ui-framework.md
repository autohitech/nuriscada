# 설계 0002. 웹 UI 프레임워크 선택 (D-2)

> 상태: **확정: Svelte 5** ([결정 0014](../decisions/0014-web-ui-svelte.md), 2026-10-18). 아래는 비교 기록이다. 결정 0002(웹 UI, TypeScript), 0003(오프라인 번들, 외부 CDN 금지), 0004(디자인 방향)를 따른다. 아래 평가는 일반 지식에서 온 추론이며 [I], 후보별 프로토타입 측정은 하지 않았다 [U]. 버전과 지원 현황은 도입 전에 최신 자료로 확인한다.

## 요구

| 요구 | 내용 | 근거 |
|---|---|---|
| R1 | 값이 자주 바뀌는 수천 개 요소를 변경분만 갱신한다 (태그 1만 개 중 일부가 100 ms 단위로 변한다) | SQ-G07, 결정 0005 |
| R2 | 오프라인 번들: 모든 자산이 패키지에 포함되고 외부 CDN·글꼴·원격 스크립트에 의존하지 않는다 | 결정 0003, SQ-O06 |
| R3 | 이후 그래픽 편집기(오브젝트 약 120종, SVG·캔버스, 속성 패널, 표)를 만들 수 있다 | SQ-G05, SQ-G08 |
| R4 | 접근성(키보드, 화면 낭독기)을 갖춘 컴포넌트를 쓸 수 있다 | SQ-U08 |
| R5 | TypeScript 일급 지원, 서버 API 타입 공유 | 설계 0001 §6 |
| R6 | 허용 등급 라이선스(MIT/Apache-2.0 등)와 낮은 의존성 수 | 의존성 정책 |
| R7 | 팀의 숙련도 (웹 프론트엔드 경험은 있다. 특정 프레임워크는 미확인) | [U] |

## 후보

| 후보 | 갱신 방식 | 번들 크기(추정) | 생태계 | 접근성 부품 | 비고 |
|---|---|---|---|---|---|
| **Svelte 5** (+ Vite, 단독 SPA) | 컴파일 시 최적화, 룬 기반 세밀한 반응성 | 작음 | 중간 | 있음(헤드리스 부품 라이브러리) | 코드가 간결하다. 편집기용 대형 부품은 직접 만들 일이 늘 수 있다 |
| **SolidJS** | 세밀한 신호, 가상 DOM 없음 | 작음 | 작음 | 있음 | 갱신 성능이 가장 직접적이다. 생태계와 인력 풀이 작다 |
| **React 19** (+ Vite) | 가상 DOM, 외부 저장소 구독으로 선택적 갱신 | 큼 | 가장 큼 | 가장 풍부 | 편집기·표·단축키·드래그 부품이 풍부하다. 고빈도 갱신은 구독 설계와 메모이제이션이 필요하다 |
| **Preact** | 가상 DOM(React 호환 계층) | 매우 작음 | React 생태계 일부 활용 | 호환 계층으로 일부 | 작은 번들과 React 부품의 절충. 호환 문제가 있을 수 있다 |
| **Lit**(웹 컴포넌트) | 웹 표준 컴포넌트 | 작음 | 작음 | 직접 | 프레임워크 중립을 얻지만 상태 관리와 편집기 부품을 직접 갖춰야 한다 |

모든 후보는 MIT 계열 라이선스로 알려져 있다 [I, 도입 시 확인].

## 제안

- **1순위: Svelte 5 + TypeScript + Vite** (SvelteKit 없이 정적 번들). 이유: 고빈도 갱신에 유리하고 번들이 작아 오프라인 패키지에 부담이 적으며, 접근성 부품이 있고 코드가 간결하다. 편집기용 대형 부품(속성 표, 도킹 레이아웃)은 직접 만들거나 프레임워크 중립 라이브러리를 쓴다 [I].
- **대안: React 19 + Vite.** 그래픽 편집기와 데이터 표 같은 대형 부품이 많아 R3에서 가장 유리하다. 런타임 화면의 고빈도 갱신은 외부 저장소와 선택적 구독으로 설계해야 한다.
- 차트·트렌드는 프레임워크와 무관한 캔버스 기반 라이브러리를 쓸 수 있다(후보 검토는 트렌드 조각에서).
- **결정 기준**: 편집기 개발을 빨리 하려면 React, 런타임 화면 성능과 번들 크기를 우선하면 Svelte. 팀의 숙련도(R7)가 판단을 바꿀 수 있다.
- 선택에 확신이 없으면 S4 시작 전에 같은 화면(태그 1만 행, 100 ms 갱신)을 두 후보로 만들어 측정하는 하루짜리 비교 시험을 권한다 [제안].

## 결정이 영향을 주는 것
S4(웹 UI 최소 화면), 디자인 토큰 구현 방식(CSS 변수 중심이라 프레임워크 중립으로 둔다), 시각 회귀 시험 도구.
