# 0017. OPC UA 연동 보류

- 상태: 보류 (2026-11-06, 출처: 사용자 질의에 대한 조사).
- 결정: OPC UA 서버 내장은 이번 단계에서 하지 않는다. 개방형 연동은 MQTT 읽기 전용 발행으로 둔다.
- 이유:
  - OPC UA 서버는 주소 공간·구독·세션에 더해 인증서(PKI) 발급·갱신·신뢰 목록 운용이 필수다. 현재 제품은 서버 자체 TLS도 두지 않았고(외부 HTTPS 프록시 전제), 인증서 운용 이야기가 없다.
  - Rust 구현(`opcua` 크레이트 계열)은 MPL-2.0이라 링크는 가능하지만, 서버 한 벌을 얹는 분량이라 한 덩어리(queue item)로 끝낼 수 없다.
  - 읽기 전용 외부 연동 수요는 MQTT 다리(`--mqtt-broker`, SQ-C06 [O])로 먼저 받는다.
- 재개 조건: 인증서 운용 방침(발급·갱신·신뢰 목록)과 공개 범위가 정해지면 별도 설계로 다룬다. 그때 Rust 크레이트 선정과 주소 공간 매핑(태그→노드)부터 시작한다.
- 영향: 요구사항 SQ-C06의 `[I] OPC UA` 표시는 유지한다.
