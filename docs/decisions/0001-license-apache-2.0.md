# 0001. 프로젝트 라이선스는 Apache-2.0

- 상태: 확정 (2026-10-18, 출처: 사용자)
- 맥락: 제품 이름은 NuriScada, 무료로 제공하고 소스를 공개하며 상업적 사용을 허용하고 개발자는 사용으로 생긴 문제에 법적 책임을 지지 않는 방침.
- 결정: Apache License 2.0.
- 이유: 상업적 사용 허용, 보증·책임 부인 조항, 명시적 특허 사용권, 기여 오픈소스에서의 해석 선례.
- 결과: GPL·AGPL 의존성은 링크하지 않는다. LGPL·MPL은 정책의 조건부 등급이다. 기여는 DCO 서명으로 받는다.
- 한계: 라이선스의 책임 부인이 모든 법역에서 전부 유효하다고 보장되지는 않는다. 안전 고지([SAFETY.md](../../SAFETY.md))를 병행한다.
