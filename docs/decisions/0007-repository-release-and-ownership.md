# 0007. 저장소 공개 시점, 소유자, 저작권 표시

- 상태: 확정 (2026-10-18, 출처: 사용자)
- 결정:

| 항목 | 결정 |
|---|---|
| 공개 시점 | **첫 동작 수직 조각이 나올 때까지 비공개**. 조건이 충족되면 공개로 전환한다 |
| 소유자 | GitHub 조직 `autohitech` (저장소 `autohitech/nuriscada`) |
| 저작권 표시 | "NuriScada contributors". 기여자는 DCO 서명으로 Apache-2.0에 따라 제공한다 |

- **공개 전환 조건** (모두 충족해야 한다):
  1. 첫 동작 수직 조각(값 환산·알람·MODBUS TCP 읽기·최소 웹 화면)이 동작하고 [성능 목표](0005-performance-targets.md)의 측정 방법으로 한 번 측정되었다.
  2. 이름 충돌 확인(OD-6)이 끝났다.
  3. 책임 제한 문구와 영상 코덱 라이선스의 법무 확인(OD-8)이 끝났거나, 해당 기능이 공개본에 없다.
  4. 보안 신고 절차와 지원 버전 정책([0008](0008-security-response-policy.md))이 `SECURITY.md`에 적혀 있고 저장소의 비공개 취약점 신고 기능이 켜져 있다.
  5. 공개본 금지 패턴 검사가 통과하고, 저장소 이력에 기존 제품의 코드·자산·이름이 없다. 이력에 한 번이라도 들어갔다면 이력을 정리한 뒤 공개한다.
  6. 의존성 라이선스 검사와 SBOM 생성이 CI에서 동작한다 ([정책](../requirements/dependency-license-policy.md)).
  7. 안전 고지([SAFETY.md](../../SAFETY.md))와 보증 부인이 README 첫 화면에서 보인다.
  8. 공개 전환은 사용자가 최종 승인한다.
- 저작권 머리말 규칙: 소스 파일 첫머리에 `SPDX-License-Identifier: Apache-2.0`과 `Copyright NuriScada contributors`를 둔다. 서드파티 코드는 원래 고지를 유지한다. 자동 검사는 구현 시작 때 CI에 넣는다 [제안].
- 비공개 동안의 작업 방식: 최종본은 분석 저장소의 준비 영역에서 만들어 검사한 뒤 올린다 (사용자 방침). 이 저장소에는 직접 커밋하지 않는다.
- 남은 결정: 조직 안의 접근 권한 구성(관리자, 쓰기 권한자)은 OD-11에서 정한다 [U].
