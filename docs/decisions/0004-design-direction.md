# 0004. 디자인 방향: 차분한 산업용, 다크 기본, 편집기와 터치 런타임 이원 설계

- 상태: 확정 (2026-10-18, 출처: 사용자)
- 결정:
  - **분위기**: 차분한 산업용. 평상시는 저채도의 회색 계열, 이상 상태만 강하게 드러나는 화면 원칙(HMI 설계 표준 적용 여부는 OD-5에서 정한다).
  - **기본 테마**: 다크 기본. 라이트와 고대비 테마를 함께 제공한다. 세 테마는 같은 의미 체계를 쓰며 어느 쪽도 부족한 완성도로 내지 않는다.
  - **사용 환경**: 데스크톱 **편집기**와 현장 터치 패널 **런타임**을 용도별로 다르게 설계한다.
- 원칙:

| 영역 | 편집기 | 런타임 |
|---|---|---|
| 입력 | 키보드·마우스 중심, 단축키, 밀도 높은 레이아웃 | 터치 우선, 큰 터치 대상, 실수 방지 확인 |
| 정보 밀도 | 높음 (속성 패널, 목록, 일괄 편집) | 낮음~중간, 핵심 값과 상태 중심 |
| 색 사용 | 구조를 나누는 중립색, 선택·오류만 강조 | 정상은 중립, 경보 우선순위만 색·형태로 강조 |
| 화면 크기 | 노트북~대형 모니터 | 소형 패널~대형 모니터, 전체 화면(키오스크) 모드 |

  - 상태는 색만으로 전달하지 않고 아이콘·형태·문구를 병행한다 (색각 이상 대응).
  - 장식 모션을 쓰지 않는다. 움직임은 상태 변화 전달에만 쓰고, 줄임 설정을 존중한다.
  - 원본 화면 파일을 열 때는 파일에 저장된 색을 그대로 그리는 충실 모드와 테마를 적용하는 모드를 구분한다 (요구사항 SQ-G06).
- 다음 단계: 디자인 토큰 초안(색 단계, 상태 색 체계, 타이포, 간격)과 핵심 화면 목업 3~4개(런타임 화면, 태그 편집기, 통신 포트 설정, 알람 목록)를 만들어 확정한다. 목업은 이 결정의 구체화이며 별도 승인을 받는다.
- 남은 결정: 적용할 HMI·알람 표준(OD-5), 성능 목표(OD-4).
