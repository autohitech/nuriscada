# 0015. 기존 제품의 태그 파일 가져오기 (범위와 한계)

- 상태: 확정 (구현 범위 결정, 2026-10-18). 형식 근거는 비공개 분석 명세이며 실제 기존 제품이 만든 파일로는 검증하지 않았다 ([0010](0010-behavior-baseline-prediction-only.md)).
- 결정: 기존 제품의 태그 파일(`Local.tagx`)을 **읽기 전용**으로 가져온다(SQ-M01). 서버 `POST /api/v1/project/import`의 `format: "tagx"`와 `default_device`로 쓰며, 기본은 미리보기이고 병합·교체는 로컬 관리자만 할 수 있다(감사 기록).
- 읽는 것: 태그 이름, 단위, 환산(장치·표시 범위, 프로파일 0·1·3·4, 지연, 범위 처리), 알람 종류와 한계·복귀 여유, 쓰기 가능 여부(출력 태그). 줄 형식은 첫 필드가 종류(`AI`, `AO`, `DI`, `DO`, `ST`, `GR`, `GDO`)이고 공통 19개 필드와 종류별 고유 필드가 뒤따른다. 빈 줄과 `;` 줄은 건너뛴다.
- 읽지 않는 것과 이유:
  - **통신 설정**: 포트, 국번, 주소의 해석은 통신 규격마다 다르다. 아날로그는 보유 레지스터, 디지털은 코일로 **추정해 옮기며 검증되지 않았다**. 보고서의 "통신 매핑" 항목이 이를 알리고, 사용자가 가져올 때 장치를 직접 고른다.
  - 문자열 태그, 출력 그룹, 스크립트 환산(필터 5), 구형 `*.TAG` 파일, 설정·화면·보고서 파일.
  - 숫자 변환 오류의 원래 처리 방식은 확인하지 않았다. 이 구현은 숫자가 아니거나 범위 밖이면 그 줄을 "읽지 못함"으로 보고한다.
- 보고서(SQ-M02): 가져온 수, 이름 충돌로 바뀐 이름, 값이 바뀐 항목(국번 범위, 지원하지 않는 필터, 사용 안 함), 무시한 항목, 읽지 못한 항목(줄 번호 포함).
- 이름: 계층을 표현하는 점(`.`)은 그대로 두고, 대소문자를 무시한 충돌은 이름 충돌 규칙으로 새 이름을 정한다.
- 후속: 포트 설정 파일(`SCAN.NNN`)의 장치 정보 가져오기, 화면 파일, 문자열 태그, 웹 가져오기 화면.
