# 0011. 프로젝트 이름: NuriScada

- 상태: 확정 (2026-10-18, 출처: 사용자). 상표 검토는 하지 않았다.
- 결정: 프로젝트 이름은 **NuriScada**다. 저장소와 패키지 이름은 `nuriscada`, 저작권 표시는 "NuriScada contributors"다.
- 배경: 처음 가칭은 같은 분야의 기존 제품과 이름이 겹쳐서 쓰지 않기로 했다. 후보를 웹, 패키지 저장소(crates.io, npm, PyPI), GitHub, 도메인(`.com .org .io .dev`의 DNS 기록)으로 1차 검색해 NuriScada를 골랐다. 검색에서 같은 이름의 제품은 찾지 못했다.
- 확인하지 않은 것 [U]:
  - 상표 데이터베이스(한국 KIPRIS, 미국 USPTO, 유럽 EUIPO 등) 조회와 상표 출원 여부
  - 도메인의 실제 등록 가능 여부 (DNS 기록만 확인)
  - 이름 일부 "Nuri"(한국어 "누리", 세상)와 "Scada"는 일반적인 말이어서 상표로 보호받기 어렵고, 비슷한 이름의 제품이 있을 수 있다
- 후속:
  - 공개 전환 전에 상표 조회를 한다 ([공개 전환 조건](0007-repository-release-and-ownership.md) 2번).
  - 패키지 이름·도메인 선점은 공개 방침이 정해진 뒤 한다.
